# Prompt Master

A Claude Code mod that rewrites a rough prompt into a clearer one before you send it. Nothing is sent automatically: the rewrite replaces your draft in the prompt box so you can review and edit it first.

- **Terminal / desktop:** click **✨ Prompt Master** in the band above the prompt box.
- **Any surface (incl. mobile):** start your message with `pm:` and send. The draft is rewritten and put back in the box instead of being sent.

Uses the session's own credentials (`sonnet`, low effort). Install by pointing Claude Code at this folder with `--plugin-dir mods/prompt-master`.
